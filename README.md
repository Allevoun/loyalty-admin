# Лояльность — административная панель (прототип фронтенда)

Read-only админка для поиска и разбора начислений/списаний бонусов в системе лояльности маркетплейса.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

`npm run build` — типизация + production-сборка.

## Стек

- Vite + React 19 + TypeScript
- react-router (browser router)
- TanStack Query — загрузка данных, курсорная пагинация, кэш
- TanStack Virtual — виртуализация строк таблицы
- Radix UI — tabs / popover / dialog / dropdown / tooltip / checkbox
- Tailwind CSS v4 — дизайн-токены, светлая + тёмная тема
- SheetJS (`xlsx`) — генерация XLSX; CSV — вручную

## Данные

Бэкенда нет. Синтетический датасет генерируется детерминированно из seed
(`src/mock/generate.ts`), индексируется (`src/mock/db.ts`) и отдаётся через
асинхронный слой с искусственной задержкой (`src/mock/api.ts`) — он же будущий
контракт API.

Опорная дата «сейчас»: **2026-09-08**, время везде — МСК.

### Основные сущности

| Сущность | Ключ | Заметки |
|---|---|---|
| `Operation` | uuid | плоская запись начисления/списания/попытки |
| `Promo` | int | акция, подтип transactional / behavioral |
| `Segment` | int | набор пользователей для поведенческих акций |
| `ManualBatch` | uuid | ручное начисление списку пользователей |
| `Rid` | строка с точками | заказ маркетплейса, он же номер заказа |

Статусы операций: `pending` (в ожидании к начислению, +14 дней после выкупа),
`credited`, `debited`, `blocked` (не проведено из-за оплаты не картой внутреннего
банка). Сгорание и отзыв бонусов — отдельные операции.

## Экраны

- `/search` — умный поиск + расширенные фильтры + таблица (вкладки, колонки, представления, экспорт)
- `/user`, `/users/:id` — карточка пользователя 360 (баланс, операции, акции, сегменты, риды)
- `/operations/:id` — карточка операции + цепочка связанных операций
- `/rids/:rid` — карточка заказа: полная цепочка начислений/списаний
- `/promos`, `/promos/:id` — каталог акций со статистикой + карточка акции
- `/segments`, `/segments/:id` — сегменты и их состав
- `/blocked` — операции, заблокированные типом оплаты
- `/exports` — очередь асинхронных выгрузок (XLSX / CSV)
- `/batches/:id` — карточка ручного начисления
